Blog-index topic filter. Exactly one pill is active — filled (ink in light, iris in dark), mono weight 500 (the only Fira Code 500). Inactive pills are quiet: soft border, body text, small dot in the topic color.

```jsx
<FilterPill active label="everything" count={19} />
<FilterPill topic="code" label="code" count={11} />
<FilterPill topic="bikes" label="bikes" count={6} />
```
